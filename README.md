## STEPS IN ADDING A NEW REPO AND A NEW FOLDER FROM YOUR LOCAL TERMINAL
1.MAKE THE CHANGES OR CODE YOU WANT TO DO
1B. DO git init.....to initialise the new repo and go and copy the SSH from the GITHUB YOU WOULD HAVE CREATED
1c. USING.... git remote add origin *ssh* you will create one on the github
2. YOU CAN CHECK THE STATUS  of the files just updated or added or created(basically what you want to push) USING..... git status
3. STAGE THE CHANGES USING..... git add .
4. commit the changes using..... git commit -m "your message"
5. FINALLY PUSH
